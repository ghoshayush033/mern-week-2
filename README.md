# Week 2 - Assignment 1: To-Do List REST API

Node.js, Express.js এবং MongoDB ব্যবহার করে তৈরি একটি সম্পূর্ণ To-Do REST API সার্ভিস।

## ফিচারসমূহ
- `GET /api/todos`: সব টাস্ক ফেচ করা
- `POST /api/todos`: নতুন টাস্ক তৈরি করা
- `PUT /api/todos/:id`: টাস্ক আপডেট এবং স্ট্যাটাস পরিবর্তন
- `DELETE /api/todos/:id`: টাস্ক মুছে ফেলা
- অন্তর্নির্মিত ফ্রন্টএন্ড UI সহ টেস্টের সুবিধা
